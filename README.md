# cli-auth-system

Консольная система учётных записей на Python: регистрация, вход, личный кабинет и панель администратора. Данные хранятся в JSON. Внешних зависимостей нет, только стандартная библиотека.

## Возможности

- **Гость:** регистрация, вход, вход как администратор
- **Пользователь:** смена пароля (с подтверждением старого), смена логина
- **Администратор:** поиск пользователей по логину, удаление пользователей, смена своего пароля
- Скрытый ввод паролей через `getpass`
- Проверка длины логина и пароля, запрет пробелов
- При первом запуске создаётся администратор по умолчанию: `admin` / `admin123`

## Запуск

Нужен Python 3.10+ (используется `match/case`).

```bash
python main.py
```

Запускайте из настоящего терминала. В консоли Run в PyCharm скрытый ввод пароля не работает: включите *Emulate terminal in output console* или используйте вкладку Terminal.

## Структура

```
main.py                  # точка входа: сборка объектов и запуск
config.py                # пути, роли, ограничения длины, админ по умолчанию
models.py                # класс User
errors.py                # иерархия исключений приложения
storage.py               # UserStorage: чтение и запись data.json
services/
  auth_service.py        # регистрация, вход, вход администратора
  user_service.py        # смена пароля и логина
  admin_service.py       # поиск и удаление пользователей
ui/
  console.py             # вывод, цвета, ввод, таблица пользователей
  password_input.py      # скрытый ввод пароля
  menus.py               # гостевое меню, личный кабинет, панель администратора
  app.py                 # главный цикл переходов между меню
```

Слои зависят только сверху вниз: `ui` → `services` → `storage` → `models`. Сервисы ничего не печатают и не спрашивают у пользователя: они бросают исключения, а меню их показывает.

## Ограничения

Учебный проект. Пароли хранятся в `data.json` **открытым текстом**, без хеширования, поэтому для реальных данных он не подходит.
